Accessibility Statement

WCAG 2.2 Level AA Standards and Inclusive Household Design

1. Our accessibility commitment

Rigour Consulting is committed to ensuring digital accessibility for people of all abilities. We actively design, test, and refine GlassSpend in alignment with the Web Content Accessibility Guidelines (WCAG) 2.2 Level AA across both our mobile application and public web properties.

2. Mobile application accessibility features

The GlassSpend Android application incorporates comprehensive accessibility engineering:

  • TalkBack screen reader support: All actionable elements, buttons, and summary cards feature explicit contentDescription semantics, clear roles, and state descriptions (such as "expanded" or "selected").
  • Dynamic font scaling (up to 200%): User interface layouts adapt responsively to system font scaling up to 200% without text truncation, clipping, or overlapping controls. Action buttons stack into full-width vertical columns when text scaling exceeds standard dimensions.
  • Touch target sizes: Interactive buttons, chips, and input fields meet or exceed the recommended minimum touch target size of 48 x 48 dp.
  • Contrast ratios: Text elements maintain a minimum contrast ratio of 4.5:1 against light and dark background surfaces, with primary headings exceeding 7:1 (WCAG AAA).
  • Sensory independence: Status indicators (such as error warnings or confirmation states) pair distinct icons and descriptive labels alongside colour cues so information is never conveyed by colour alone.
  • Hardware and keyboard navigation: Full focus order support for external keyboards and directional switch devices.

3. Web accessibility standards

This public information website has been built to conform with accessible markup standards:

  • Semantic HTML5 landmark regions (<header>, <main>, <nav>, <article>, <footer>).
  • Logical heading hierarchy (H1 through H3) for seamless screen reader outline navigation.
  • High contrast text colours matching WCAG AAA for body paragraphs and headings.
  • Responsive design supporting 400% zoom without horizontal scrolling.
  • Clear focus-visible outlines on all interactive links and buttons.
