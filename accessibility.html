Accessibility Statement

WCAG 2.1 Level AA Compliance & Inclusive Household Design

1. Our Accessibility Commitment

Rigour Consulting is committed to ensuring digital accessibility for people of all abilities. We actively design, test, and refine GlassSpend in alignment with the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA across both our mobile application and public web properties.

2. Mobile Application Accessibility Features

The GlassSpend Android application incorporates comprehensive accessibility engineering:

  • TalkBack Screen Reader Support: All actionable elements, buttons, and summary cards feature explicit contentDescription semantics, clear roles, and state descriptions (such as "expanded" or "selected").
  • Dynamic Font Scaling (up to 200%): User interface layouts adapt responsively to system font scaling up to 200% without text truncation, clipping, or overlapping controls.
  • Touch Target Sizes: All interactive buttons, chips, and input fields meet or exceed the recommended minimum touch target size of 48 x 48 dp.
  • Contrast Ratios: Text elements maintain a minimum contrast ratio of 4.5:1 against light and dark background surfaces, with large headings exceeding 7:1.
  • Sensory Independence: Status indicators (such as error warnings or confirmation states) pair distinct icons and descriptive labels alongside colour cues so information is never conveyed by colour alone.
  • Hardware & Keyboard Navigation: Full focus order support for external Bluetooth keyboards and directional switch devices.

3. Web Accessibility Standards

This public information website has been built to conform with modern accessible markup standards:

  • Semantic HTML5 landmark regions (<header>, <main>, <nav>, <article>, <footer>).
  • Logical heading hierarchy (H1 through H3) for seamless screen reader outline navigation.
  • High contrast text colours matching WCAG AAA for body paragraphs.
  • Responsive design supporting 400% zoom without horizontal scrolling.
